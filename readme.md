### How to run the project:

1. Open a terminal in the backend folder:
   cd Card_Games/backend
   .\venv\Scripts\activate
   python manage.py runserver

2. Open another terminal in the frontend folder:
   cd Card_Games/frontend
   npm install
   npm run dev

3. Open the local frontend URL shown in the terminal (usually http://localhost:5173)

Notes:
- Use the backend terminal for Django API and WebSocket server
- Use the frontend terminal for the React app
- The table should fit the screen properly in the browser
